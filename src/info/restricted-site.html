Get Clone can't act on this site

Firefox blocks extensions from running on a short list of domains it "quarantines" by default, to limit the blast radius if a malicious extension is ever discovered. This domain is on that list, so Get Clone has no access here until you allow it.

To fix it

  1. Click the button below to open the Add-ons Manager.
  2. Find Get Clone in the list and click it.
  3. Under Details, toggle Run on sites with restrictions on.
  4. Come back and try again.

Get Clone only ever moves data between containers, locally, on your own machine — cookies and site storage never leave your device. Allowing it here doesn't change that. You can read Mozilla's own explanation of quarantined domains at support.mozilla.org/kb/quarantined-domains.
